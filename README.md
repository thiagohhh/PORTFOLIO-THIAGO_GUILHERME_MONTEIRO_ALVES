# PORTFOLIO-THIAGO_GUILHERME_MONTEIRO_ALVES

## Pastas principais
- FRONTEND/  -> React (Vite)
- BACKEND/   -> API Node

## components
```
src/components/
  admin/     -> login, cadastro, editar, minhas atividades
  layout/    -> Header, Rodape, menus, cards
  sesi/      -> tudo do portifolio Sesi
  senai/     -> tudo do portifolio Senai
  QuemSouEu.jsx
  IntroAnimacao.jsx
```

## Como rodar
```
cd BACKEND e npm i e npm run dev
cd FRONTEND e npm i e npm run dev
```
